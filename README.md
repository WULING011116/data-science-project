Data Science Project: Automobile Sales Data Cleaning & Missing Value Processing

1. The problem or research question
  - How to effectively clean real-world datasets, handle missing values, and transform vehicle sales data for reliable analysis?

2. Dataset source and usage permissions
  - Dataset: Automobile Sales dataset (`car_sales.csv` and `car_sales_missing.csv`).
  - Usage: Educational and academic coursework usage.

3. Methods and tools used
  - Tools: Python, Jupyter Notebook, Pandas.
  - Methods: Missing value detection, mean imputation (`fillna`), dropping missing rows (`dropna`), data type conversion, column derivation, string parsing, and data shuffling.

4. Key findings and one limitation
  - Key Findings: Successfully handled missing odometer and price values, corrected data types, and transformed fuel economy and currency formats for subsequent analysis.
  - Limitation: The dataset size is relatively small and focuses only on basic vehicle attributes and synthetic missing values.

5. Instructions for running the analysis
  1. Clone the repository or download the files.
  2. Ensure Python and the `pandas` library are installed.
  3. Open the Jupyter Notebook file (`MC648566_Exercise1_06.ipynb`) and run the cells sequentially.
