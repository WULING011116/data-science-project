Data Science Project: Automobile Sales & Economic Indicators Analysis

1. The problem or research question
- How do economic recessions, unemployment rates, and consumer confidence impact automobile sales and advertising expenditure?

2. Dataset source and usage permissions
- Dataset: Automobile Sales / Historical Wildfires dataset provided by IBM Skills Network.
- Usage: Educational and academic coursework usage.

3. Methods and tools used
- Tools: Python, Jupyter Notebook, Pandas, Matplotlib, Seaborn, Folium.
- Methods: Data cleaning, grouping, aggregations, trend analysis, correlation scatter plots, and geographical choropleth mapping.
4. Key findings and one limitation
- Key Findings: Automobile sales drop significantly during recession periods, and consumer confidence is strongly correlated with purchasing trends.
- Limitation: The dataset is limited to specific macroeconomic indicators and historical spans.

5. Instructions for running the analysis
1. Clone the repository or download the files.
2. Ensure Python and required libraries (`pandas`, `seaborn`, `matplotlib`, `folium`) are installed.
3. Open the Jupyter Notebook file and run the cells sequentially.
